# Catatau-lib

> Um repositório dedicado ao armazenamento e organização de bibliotecas, módulos e filtros customizados para reutilização em projetos futuros de sistemas embarcados (Arduino/PlatformIO).

---

## Funcionalidade
A ideia deste espaço é centralizar códigos modulares de forma que eu possa simplesmente copiá-los e colá-los na pasta `lib` ou `src` de novos projetos, evitando reescrever a mesma lógica várias vezes.

---

## Como reutilizar
1. Copie a pasta da biblioteca desejada dentro deste repositório.
2. Cole-a dentro da pasta `lib/` do seu projeto no **PlatformIO** (ou na pasta do seu projeto Arduino).
3. Faça o `#include` no seu arquivo principal (ex: `main.cpp`).
